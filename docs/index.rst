httpp
=====

httpp is a C++ HTTP library (server, client, downloads, progress bars, URL helpers) with a Python layer on top.
The user documentation is the ``README.md`` in the repository root and the examples under ``examples/``.

Project documents (Markdown, in this directory):

* ``Architecture.md``: goals, layers and the open risks
* ``agent.md``: the working rules for contributors and agents
* ``adr/``: one architecture decision record per decision, indexed in ``adr/README.md``

The repository root also holds ``checklist.md`` (the plan and its status) and ``CHANGELOG.md``.
