<Only lang="python">

```bash
pip install httpp
```

Python 3.8 or newer. The wheel contains the Python package, the `httpp` command line tool and the compiled C++ library with its headers, so the same install also serves [C++ projects](#use-it-from-c).

</Only>

<Only lang="cpp">

The C++ library comes with the Python wheel, or you can build it from source. Switch to Python in the top bar for the one-line install.

</Only>

## Use it from C++

There are two ways to get the C++ library.

**From the wheel.** `pip install httpp`, then ask the package where its CMake config lives:

```cmake
cmake_minimum_required(VERSION 3.15)
project(app LANGUAGES CXX)
set(CMAKE_CXX_STANDARD 17)

find_package(Python3 REQUIRED COMPONENTS Interpreter)
execute_process(
    COMMAND ${Python3_EXECUTABLE} -c "import httpp; print(httpp.get_cmake_dir())"
    OUTPUT_VARIABLE httpp_DIR
    OUTPUT_STRIP_TRAILING_WHITESPACE
    COMMAND_ERROR_IS_FATAL ANY
)
find_package(httpp CONFIG REQUIRED)

add_executable(app main.cpp)
target_link_libraries(app PRIVATE httpp::httpp_core)
```

This is the setup the project's own install test uses (`tests/cmake/consumer_project`). In your code, `#include <httpp.h>` is the only header you need.

**From source.** You need CMake 3.21 or newer and a C++17 compiler. Clone with the submodules:

```bash
git clone --depth 1 --recurse-submodules --shallow-submodules https://github.com/mohammadraziei/httpp.git
cmake -B build -G Ninja -DHTTPP_BUILD_TESTS=ON
ninja -C build
```

The README has the details on offline builds and where Asio is found.
