`serve_directory` makes a folder of files part of the server, like `python -m http.server` but inside your app. Use it for a site's images, scripts and pages, and for any file whose name the visitor chooses.

## From the command line

With no app to write, one command hands out a folder, as `python -m http.server` does:

```bash
httpp server public
# Serving '/home/you/public' at http://0.0.0.0:8000/
```

The folder defaults to the current one, and `Ctrl+C` stops it. Each request is logged on one line (`GET /notes.txt 200`). On a terminal it also prints a small banner first; `--no-banner` turns that off, and a pipe or a log file never gets it.

| | `python -m http.server` | `httpp server` |
|---|---|---|
| The folder | `--directory public` | `public` |
| The port | `8000` | `-p 8000` (default `8000`) |
| The address | `--bind 127.0.0.1` | `--host 127.0.0.1` (default `0.0.0.0`) |
| A folder without `index.html` | lists its files | answers 404 |
| Names that start with a dot | served | answer 404 (`--hidden` serves them) |

`--no-dates` sends no file times: no `Last-Modified` and no `ETag`, so the files' modified times stay private and a browser always asks again (`Cache-Control: no-cache`). `--shutdown-timeout SECONDS` (default `10`) is how long requests in progress may take to finish on `Ctrl+C`, and `--log-level` (`trace`, `debug`, `info`, `warning`, `error` or `off`, default `info`) says what goes to stderr.

:::warning

The command listens on every interface, so anyone on your network can read the folder. Add `--host 127.0.0.1` to keep it on your computer. Names that start with a dot (`.env`, `.git`) answer 404, so they are not handed out by accident; pass `--hidden` only when you mean to serve them, for example `/.well-known/` for a certificate check.

:::

To let people see what is in a folder instead of asking for a file by name, run [`httpp browse`](browse-command.mdx), which adds a listing, a preview and ZIP downloads.

The command is the `Directory` below, mounted at `/` with `set_show_hidden(false)` (unless `--hidden`) and `set_show_dates(false)` (with `--no-dates`), so everything on this page about names, `index.html` and file types applies to it. The one difference from `serve_directory`: that call serves names that start with a dot, as the next sections say.

## In your own server

<Lang name="serve_folder" />

With a `public` folder that holds `index.html` and `notes.txt`:

```bash
curl http://127.0.0.1:8000/static/notes.txt   # the file public/notes.txt
curl http://127.0.0.1:8000/static/            # public/index.html
curl -i http://127.0.0.1:8000/static/nope.txt # 404
```

## What the code does

The first argument is the path in the URL and the second is the folder on disk. Everything under the folder is reachable below the mount path. A path that ends in `/`, and the mount path itself, answer with that folder's `index.html`. The type of each file comes from its extension.

By default **files whose names start with a dot are served too**: `public/.env` would answer at `/static/.env`. Keep such files out of the folder, or switch that off with `set_show_hidden(false)`, as shown below.

The [hooks](hooks.mdx) of the server run for these requests as well, so a `before` hook can ask for a key before any file is handed out.

## Settings

`serve_directory(mount, folder)` is the short form. For anything else use `Directory` (`httpp::directory` in C++), whose settings are methods that return it, so they chain:

<Only lang="cpp">

```cpp
httpp::directory("public")
    .set_show_hidden(false)        // a path with a dot-name in it answers 404, whatever is on disk
    .set_show_dates(false)         // no Last-Modified and no ETag: the times of the files stay private
    .set_download_active(true)     // html, svg and other types that can run code in the page are downloaded, not shown
    .mount(app, "/static");
```

</Only>

<Only lang="python">

```python
httpp.Directory("public").set_show_hidden(False).set_show_dates(False).set_download_active(True).mount(app, "/static")
# or, with keywords: httpp.Directory("public", show_hidden=False, show_dates=False, download_active=True).mount(app, "/static")
```

</Only>

`set_show_dates(bool)` (default `true`) is the switch for the times of the files. With `false` there is no `Last-Modified` and no `ETag` (it holds the time too), so no request can get a 304 and a browser asks again each time (`Cache-Control: no-cache`); a range request still gets its part, but one that carries `If-Range` cannot be checked and gets the whole file. `set_index(bool)` (default `true`) is the switch for the `index.html` answer. `set_download_active(true)` also adds `X-Content-Type-Options: nosniff`, and `?download=1` on any file asks for a download. `mount` raises `ValueError` (Python) or `std::invalid_argument` (C++) when the mount path does not start with `/`. To list a folder for people to browse, see the [file browser](file-browser.mdx).

## Where the two differ

| | Python | C++ |
|---|---|---|
| Short call | `app.serve_directory(mount, folder)` | `app.serve_directory(mount, folder)` |
| With settings | `httpp.Directory(folder).set_...().mount(app, mount)` | `httpp::directory(folder).set_...().mount(app, mount)` |
