`serve_directory` makes a folder of files part of the server, like `python -m http.server` but inside your app. Use it for a site's images, scripts and pages, and for any file whose name the visitor chooses.

<Lang name="serve_folder" />

With a `public` folder that holds `index.html` and `notes.txt`:

```bash
curl http://127.0.0.1:8000/static/notes.txt   # the file public/notes.txt
curl http://127.0.0.1:8000/static/            # public/index.html
curl -i http://127.0.0.1:8000/static/nope.txt # 404
```

## What the code does

The first argument is the path in the URL and the second is the folder on disk. Everything under the folder is reachable below the mount path. A path that ends in `/`, and the mount path itself, answer with that folder's `index.html`. The type of each file comes from its extension.

By default **files whose names start with a dot are served too**: `public/.env` would answer at `/static/.env`. Keep such files out of the folder, or switch that off with `set_show_hidden(false)`, as shown below.

The [hooks](hooks.mdx) of the server run for these requests as well, so a `before` hook can ask for a key before any file is handed out.

## Settings

`serve_directory(mount, folder)` is the short form. For anything else use `Directory` (`httpp::directory` in C++), whose settings are methods that return it, so they chain:

<Only lang="cpp">

```cpp
httpp::directory("public")
    .set_show_hidden(false)        // a path with a dot-name in it answers 404, whatever is on disk
    .set_download_active(true)     // html, svg and other types that can run code in the page are downloaded, not shown
    .mount(app, "/static");
```

</Only>

<Only lang="python">

```python
httpp.Directory("public").set_show_hidden(False).set_download_active(True).mount(app, "/static")
# or, with keywords: httpp.Directory("public", show_hidden=False, download_active=True).mount(app, "/static")
```

</Only>

`set_index(bool)` (default `true`) is the switch for the `index.html` answer. `set_download_active(true)` also adds `X-Content-Type-Options: nosniff`, and `?download=1` on any file asks for a download. `mount` raises `ValueError` (Python) or `std::invalid_argument` (C++) when the mount path does not start with `/`. To list a folder for people to browse, see the [file browser](file-browser.mdx).

## Where the two differ

| | Python | C++ |
|---|---|---|
| Short call | `app.serve_directory(mount, folder)` | `app.serve_directory(mount, folder)` |
| With settings | `httpp.Directory(folder).set_...().mount(app, mount)` | `httpp::directory(folder).set_...().mount(app, mount)` |
