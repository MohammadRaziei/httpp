httpp is an HTTP client and server for Python and C++, built from one core. The server needs no separate process and the library needs no system packages.

The code on every page follows the language you pick in the top bar. Your choice is remembered, and `?lang=cpp` or `?lang=python` in a link preselects it. Where the two APIs differ, the page says so in text and in a table at the bottom.

## Where to start

1. [Install](install.mdx) the Python package or build the C++ library.
2. [Answer a GET request](server/get-route.mdx) with a route that takes a path parameter.
3. Read what came in: [request data](server/request-data.mdx). Shape what goes out: [responses](server/responses.mdx).
4. Serve files: [send one](server/send-file.mdx), [serve a folder](server/serve-directory.mdx) or [browse files](server/file-browser.mdx).
5. Run code around every request with [hooks](server/hooks.mdx).
6. Call a server: [GET requests](client/get-request.mdx) and [requests with a body](client/post-request.mdx).
7. Save a file: [download](client/download.mdx), with a checksum, resume and no blocking.

## What is not here yet

These areas exist in the library and are documented only in the project README for now: routers, forms and uploads, streaming responses, async handlers, WebSocket, TLS, sessions, the command line and testing your app.
