## Servers

All servers answer the same requests with the same work: a constant string, a path parameter turned into a JSON object, and about 60 µs of
CPU-bound work. The load generator is [oha](https://github.com/hatoo/oha), pinned to other CPUs than the server.

## HTTP clients

Each library makes GET requests in a loop against the same server, in a process of its own. Sync libraries get one thread and one session each,
async libraries one session and one task per connection.

## Run it yourself

```bash
benchmarks/run.sh full
```

The run writes `benchmarks/results/<time>.json`, with the hardware of the machine in it (CPU, cores, memory, OS). Commit that file and the next build of this site shows it (`scripts/prepare.py bench`
reads every file there that is marked `"purpose": "published"`). See `benchmarks/README.md` for every setting.
